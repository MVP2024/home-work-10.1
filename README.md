# Проект банковских операций клиента

## Описание проекта

_Данный проект представляет собой скрипт на Python, который реализует функции для обработки и маскирования данных, таких
как номера карт и счетов.
Он также включает функции для фильтрации и сортировки списка данных, содержащих информацию о различных элементах._

### Основные цели проекта

- Фильтрация данных по ключу `state`.
- Сортировка данных по ключу `date`.
- Маскировка номеров счетов и карт.
- Генерация и фильтрация транзакций по валюте.
- Генерация описаний транзакций.
- Генерация номеров карт
-

***Функция***
`get_mask_card_number(card_number: Union[str]) -> Union[str]`

**Описание:**
_Принимает на вход номер карты и возвращает его маскированный вид. Номер отображается в формате_ XXXX XX** **** XXXX, 
_где видны первые 6 и последние 4 цифры._

*Пример:*
    - masked_card = get_mask_card_number("7000792289606361")
    - print(masked_card)  # Вывод: "7000 79** **** 6361"

последние 4 цифры._

    - masked_account = get_mask_account("73654108430135874305")

***Функция***
`convert_to_rub(transaction: Dict[str, Any]) -> float`

_Конвертирует сумму из указанной валюты в рубли (RUB)._

- **Параметры**:
  - `transaction`: Словарь, представляющий транзакцию, который должен содержать поле `operationAmount` с полями:
    - `amount` (число в виде строки)
    - `currency` (словарь с полем `code`, указывающим код валюты).

- **Исключения**:
  - `ValueError`: 
    - Если транзакция не содержит поле `operationAmount`.
    - Если API не возвращает курс для RUB.
    - Если не удается получить обменный курс.

- **Возвращаемое значение**: 
  - Конвертированная сумма в рублях (RUB).

- **Пример использования**:
  ```
  transaction = {
      "operationAmount": {
          "amount": "1000",
          "currency": {"name": "USD", "code": "USD"}
      }
  }
  rub_amount = convert_to_rub(transaction)
  print(rub_amount)  # Предположим, что курс USD к RUB равен 75.0, результат будет 75000.0 
  ```


***Функция***
`load_transactions(file_path: str) -> List[Dict[str, Any]]`

Загружает данные о транзакциях из JSON-файла.

- **Параметры**:
  - `file_path`: Путь до JSON-файла.

- **Возвращаемое значение**: 
  - Список словарей с данными о транзакциях или пустой список, если файл не найден или данные некорректны.

- **Пример использования**:
  ```
  transactions = load_transactions('path/to/your/transactions.json')
  print(transactions)  # Выводит список транзакций или пустой список
  ```


##### Тестирование

1. Для работы функции и тестов требуется установленный пакет pytest.
2. Установите необходимые зависимости.
3. Установить его можно с помощью:

``` 
pip install pytest
```

4. Для запуска тестов используйте следующую команду:

**В модулях с тестами имеется конструкция:** 
```
if __name__ == "__main__": pytest.main()`
```

```Можно запустить все тесты, фикстуры в каждом модуле отдельно```

  Для запуска из терминала:
**Или например для функций из модуля `processing.py`:**  
  ```
  pytest tests/test_processing.py
  ```

5. Для запуска всех тестов используйте команду:

```
pytest
```

6. Для запуска тестов с оценкой покрытия используйте команду:
```При активированном виртуальном окружении.```
```
6. pytest --cov
 ``` 

 ```Через poetry.```
```
poetry run pytest --cov
``` 

 ```Чтобы сгенерировать отчет о покрытии в HTML-формате```
```
pytest --cov=src --cov-report=html
 ```

7. Для проверки какие тесты пропущены введите команду:
```Src это модуль в котором мы ищем пропуски.```
```
pytest --cov=src --cov-report=term-missing
``` 

8. Для проверки какие тесты пропущены в папке tests.
``` Tests это модуль, в котором мы ищем пропуски.```
```
pytest --cov=tests --cov-report=term-missing
```
