# Проект банковских операций клиента.


## Описание проекта

Данный проект представляет собой скрипт на Python, который реализует функции для вывода карт и счетов со скрытыми номерами, 
а также фильтрации и сортировки списка данных, содержащих информацию о различных элементах.

## Основные цели проекта:

- Фильтрация данных по ключу `state`.
- Сортировка данных по ключу `date` .
- Скрытие номеров счёта.

1. Установить [Python](https://www.python.org/downloads/) (рекомендуется версия 3.6 и выше).
2. Клонировать репозиторий на локальный компьютер:
```
git clone git@github.com:ваш_пользователь/название_репозитория.git
```
3. Установите необходимые зависимости:
```
pip install -r requirements.txt
```
4. Создайте файл *.env* в корневом каталоге проекта и добавьте ваш *API* ключ, (он же токен или API token):
```commandline
EXCHANGE_API_KEY=*ваш_ключ_api*
```
5. Перейдите в директорию проекта

### Функции


1. Функция ```get_mask_card_number``` для маскировки номера банковской карты.


**Описание:**

Функция ```get_mask_card_number``` принимает на вход номер карты и возвращает ее маску. 
Номер карты замаскирован и отображается в формате 
XXXX XX** **** XXXX, где 
X - это цифра номера. То есть видны первые 6 цифр и последние 4 цифры, остальные символы 
отображаются звездочками, номер разбит по блокам по 4 цифры, разделенным пробелами.
Если номер карты меньше или больше 16 символов или в номере кроме цифр присутствуют другие символы,
то возвращает ошибку.
Пример работы функции:

# Входной аргумент 
7000792289606361 
# Выход функции
7000 79** **** 6361


2. Функция ```get_mask_account``` для маскировки номера банковского счета.


**Описание:**

Функция ```get_mask_account``` принимает на вход номер счета и возвращает его маску. 
Номер счета замаскирован и отображается в формате 
**XXXX, где 
X - это цифра номера. То есть видны только последние 4 цифры номера, 
а перед ними - две звездочки. Пример работы функции:
Если номер счёта меньше или больше 16 символов или в номере счёта кроме цифр присутствуют другие символы,
то возвращает ошибку.
Пример работы функции:

# Входной аргумент
73654108430135874305 

# Выход функции
**4305 


3. Функция ```mask_account_card``` обработки информации о картах и о счетах. 


**Описание:**

Функция ```mask_account_card``` принимает на вход тип и номер карты или счета и возвращает их тип и маскированный номер. 
Номер карты замаскирован и отображается в формате Visa Platinum XXXX XX** **** XXXX, если указан счёт, 
Номер счета замаскирован и отображается в формате 
Счет **4305, где 
X - это цифра номера.
Если номер счёта или карты, меньше или больше 16 символов или в номере счёта кроме цифр 
присутствуют другие символы, то возвращает ошибку.
Пример работы функции:

# Входной аргумент
Visa Platinum 7000792289606361
Maestro 7000792289606361
Счет 73654108430135874305

# Выход функции
Visa Platinum 7000 79** **** 6361
Maestro 7000 79** **** 6361
Счет **4305 


4. Функция ```get_date``` обработки формата даты.

**Описание:**

Функция ```get_date``` принимает на вход строку с датой в формате: "2024-03-11T02:26:18.671407", и возвращает 
строку с датой в формате: ДД.ММ.ГГГГ.
При неправильном формате возвращает ошибку, в какой строке допущена ошибка.
Пример работы функции:

# Входной аргумент
"`2024-03-11T02:26:18.671407`"

# Выход функции
`11.03.2024`


5. Функция ```sort_by_date``` сортирует список словарей по аргументу date.

**Описание:**

Функция ```sort_by_date``` принимает список словарей и необязательный параметр, задающий порядок сортировки и
возвращает новый список словарей, отсортированный по дате на убывание(по-умолчанию).

# Входной аргумент
[{"id": 41428829, "state": "EXECUTED", "date": "2019-07-03T18:35:29.512364"}, {"id": 939719570, "state": "EXECUTED", "date": "2018-06-30T02:08:58.425572"}, {"id": 594226727, "state": "CANCELED", "date": "2018-09-12T21:27:25.241689"}, {"id": 615064591, "state": "CANCELED", "date": "2018-10-14T08:21:33.419441"}]

# Выход функции
[{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}, {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}, {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}]


6. Функция ```filter_by_state``` фильтрует список словарей по ключу state с аргументом.

**Описание:**

Функция ```filter_by_state``` принимает список словарей по ключу `state` с определённым аргументом по умолчанию `'EXECUTED'`
и возвращает новый список словарей, содержащих только те, у которых ключ `state` соответствует заданному значению.
Пример работы функции:

# Входной аргумент
[{"id": 41428829, "state": "EXECUTED", "date": "2019-07-03T18:35:29.512364"}, {"id": 939719570, "state": "EXECUTED", "date": "2018-06-30T02:08:58.425572"}, {"id": 594226727, "state": "CANCELED", "date": "2018-09-12T21:27:25.241689"}, {"id": 615064591, "state": "CANCELED", "date": "2018-10-14T08:21:33.419441"}]
# Выход функции
[{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}]

**Тестирование**

Примеры тестов
Тест на фильтрацию по состоянию:

Проверяет, что функция возвращает правильные элементы для различных значений state.
Тест на пустой список:

Убедитесь, что функция корректно обрабатывает пустой входной список.
Тест на отсутствие ключа state:

Проверяет, что функция возвращает сообщение об ошибке, если ключ state отсутствует в словаре.
Тест на значение None для ключа state:

Убедитесь, что функция корректно обрабатывает случаи, когда значение для ключа state равно None.
Запуск тестов
Для запуска тестов используйте следующую команду в терминале:

pytest tests/test_processing.py
